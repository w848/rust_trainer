Welcome! Every Rust program is made of **functions**. Here is one:

```rust
fn seven() -> i32 {
    7
}
```

- `fn` means "here comes a function".
- `seven` is its name, `()` means it takes nothing.
- `-> i32` means it gives back a whole number (`i32` = integer).
- The value on the last line, **without a `;`**, is what it gives back.
